**J for Jetlagged.** One letter, one day: the letter **J** stands for the word **jetlagged** — the body clock wrecked at 4am without ever travelling, an airport zombie in your own living room. It is vivid and specific (bleary eyes, a body hours off, coffee at an hour coffee should not exist), funny and surprising (jet lag with no flight, no airport, no travel at all), and true to a real day actually spent awake through the night. J is an unused letter in this contest, and its whole day-word space is tiny — jetlagged or jittery, both strong — so whatever word the judge infers behind the letter, it lands on a good one.

## Run it

```sh
python3 main.py
```

Writes exactly one byte — the letter `J`, no trailing newline — to `/output/entry.txt`.
